# Dia 1.41.1（84131）发布验收

正式发布补丁前，必须在 Apple Silicon Mac 上完成全部检查。

## 环境

- macOS 14、15 和当前稳定版至少各一台或一个干净测试用户。
- 官方 Dia 1.41.1（84131），原始签名验证通过。
- 一个新 Dia 配置和一个已有登录、同步、扩展的配置。
- 浅色与深色外观。

## 安装与回滚

- `audit` 不修改 Dia.app 或用户数据。
- 错误版本、缺少 `zh_CN/locale.pak`、缺少 WebUI 目录时拒绝安装。
- `apply` 前完整备份成功，备份可独立解压。
- 中断资源复制、WebUI 替换、签名和启动步骤时自动恢复。
- `restore` 后 `codesign --verify --deep --strict` 通过，官方签名恢复。
- 不恢复旧备份覆盖一个构建号更高的 Dia。

## 界面覆盖

- macOS 菜单栏：Dia、文件、编辑、显示、标签页、书签、历史记录、扩展程序、
  窗口、帮助。
- 标签页：新建、关闭、固定、静音、复制、移动、分屏和恢复关闭。
- 地址栏：搜索、访问网址、粘贴并前往、站点权限。
- 侧栏、新标签页、聊天面板、上下文选择器和错误状态。
- Settings 的所有导航项和详情页。
- Skills、Memory、Personalization、Connect Apps、Morning Brief。
- 书签、历史、下载、密码、扩展、权限、PDF 和更新器。
- 首次启动、导入、默认浏览器、登录和错误弹窗。

记录任何英文残留，并区分：

- Dia 本地固定 UI：必须修复。
- 第三方扩展：不在范围内。
- 普通网页：不在范围内。
- AI 实时回答或 prompt 生成内容：不在范围内。
- 服务端新下发文案：进入下一版翻译清单。

## 功能完整性

- 登录状态保留。
- 同步正常，书签和历史无丢失。
- 新建聊天、引用当前标签页、发送和停止回答正常。
- Chrome 扩展可以启用、禁用和更新。
- 默认浏览器设置正常。
- 检查更新和下一次官方自动更新正常。
- 摄像头、麦克风、通知、下载和剪贴板权限正常。

## 排版

- 浅色和深色模式均无明显截断或重叠。
- 按钮、菜单、表单标签和提示文本支持中文长度。
- 快捷键符号、变量占位符、URL、品牌名和数字未被错误翻译。
